Como utilizar este diretório regional

A base fornecida inclui 27 municípios de Itapúa, com 439.660 habitantes segundo os registros do Censo 2022. Os 27 registros municipais não representam necessariamente toda a divisão administrativa oficial. A tabela compara somente as cidades incluídas.
