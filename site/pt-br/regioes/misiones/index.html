Como utilizar este diretório regional

A base fornecida inclui 7 municípios de Misiones, com 102.741 habitantes segundo os registros do Censo 2022. Os 7 registros municipais não representam necessariamente toda a divisão administrativa oficial. A tabela compara somente as cidades incluídas.
