Como utilizar este diretório regional

A base fornecida inclui 17 municípios de Caaguazú, com 410.253 habitantes segundo os registros do Censo 2022. Os 17 registros municipais não representam necessariamente toda a divisão administrativa oficial. A tabela compara somente as cidades incluídas.
